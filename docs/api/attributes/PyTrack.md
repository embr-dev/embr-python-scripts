### `name`

- **Type:** `str`
- **Description:** The name of the Track.

### `hidden`

- **Type:** `bool`
- **Description:** The hidden status of the Track.
- **Value range:** True · False

### `locked`

- **Type:** `bool`
- **Description:** The locked status of the Track.
- **Value range:** True · False

### `stereo_linked`

- **Type:** `bool`
- **Description:** The stereo link status of the Track.
- **Value range:** True · False

### `selected_segments`

- **Type:** `list`
- **Description:** Return a list of PySegment currently selected. Parent page: Autodesk Flame Python: flame module
