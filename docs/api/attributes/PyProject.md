### `shotgrid_project_name`

- **Type:** `str`
- **Description:** The name of the linked Flow Production Tracking project.

### `working_colour_space`

- **Type:** `str`
- **Description:** The working colour space of the Project.

### `action_colour_space`

- **Type:** `str`
- **Description:** The colour space used to render in Action. Parent page: Autodesk Flame Python: flame module
