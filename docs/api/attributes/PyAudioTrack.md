### `expanded`

- **Type:** `bool`
- **Description:** The expanded status of the Version or Audio Track.
- **Value range:** True · False

### `selected_segments`

- **Type:** `list`
- **Description:** Return a list of PySegment currently selected.

### `solo`

- **Type:** `bool`
- **Description:** The solo status of the Track.
- **Value range:** True · False

### `mute`

- **Type:** `bool`
- **Description:** The transparency attribute of the Front input of the Comp node.
- **Value range:** True False Parent page: Autodesk Flame Python: flame module
